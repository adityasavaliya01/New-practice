# 6.4 Summary Report

In this practical, I completed five mini-projects covering different areas of deep learning, computer vision and natural language processing. The first task was an Artificial Neural Network (ANN) for multi-class classification using the Wine Recognition dataset from scikit-learn. It contained 178 samples, 13 chemical features and three wine classes. The second task used OpenCV for image processing and face detection. I worked with four images from scikit-image—Astronaut, Coffee, Chelsea and Rocket—and one personal image. I applied BGR-to-HSV conversion, colour masking, erosion, dilation, Sobel edge detection and Haar Cascade face detection. The third task was handwritten digit recognition using a Convolutional Neural Network (CNN) and an ANN baseline on the MNIST dataset. I used 20,000 training images and 4,000 test images. The fourth task was time-series forecasting with a GRU network using the Melbourne Daily Minimum Temperatures dataset, containing 3,650 daily records from 1981 to 1990. The fifth task explored Transformer pipelines for fill-mask prediction, question answering and text generation using five India-related paragraphs and pre-trained Hugging Face models.

One of the most useful new concepts I learned was how different neural network architectures handle different types of data. In particular, I learned that CNN filters automatically extract spatial features such as edges and shapes from images, while GRU gates control how information is retained or forgotten across a sequence. I also learned that Transformers use attention to identify relationships between words without processing every token strictly one after another. The practical helped me understand why choosing an architecture according to the data is important.

The ANN achieved 94.44% test accuracy on the Wine dataset. In OpenCV, Haar Cascade detected one face in the five-image collection: the Astronaut image. The CNN achieved 97.62% test accuracy on MNIST, compared with 95.65% for the ANN baseline. The CNN also used fewer parameters: 56,714 compared with 109,386 for the ANN. For temperature forecasting, the GRU achieved an RMSE of 2.23°C and an MAE of 1.75°C. Its RMSE was lower than the naive baseline RMSE of 2.48°C. In the Transformer question-answering task, 7 out of 10 answers were marked correct after manual checking. The fill-mask and text-generation tasks also demonstrated how pre-trained models predict missing words and generate continuations, although generated text was not always factually reliable.

If I had more time and computing resources, I would test more ANN and CNN architectures, tune hyperparameters, and use the full MNIST dataset. I would also evaluate face detection on more varied images and compare Haar Cascade with a modern deep-learning detector. For the GRU, I would experiment with longer look-back windows and additional time-series features. For Transformers, I would use larger or more suitable models, improve the question-answering evaluation, and add retrieval from trusted sources with fact-checking. Overall, these tasks gave me practical experience in preprocessing data, building and evaluating models, interpreting results and understanding the strengths and limitations of different approaches.
